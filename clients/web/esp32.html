Plug in the board

Connect an ESP32 or ESP32-C3 to this device with a USB data cable. It becomes a Bluetooth keyboard that types your dictation anywhere.

Board not listed?

It is usually called CP2102, CH340 or USB JTAG/serial debug unit. Try another cable: many only carry power. On Windows and macOS, CH340 boards need their driver.

Wi-Fi and name

The name is what devices see when pairing over Bluetooth. The password stays on the board.

Advanced

How the board reaches this server over Wi-Fi. Change it if the board is on another network, or if this name only resolves on this device (such as .local).

Keep the board plugged in and this page open.

If the board does not respond: hold BOOT, press and release RESET (or EN), release BOOT, then try again.

Pair it

  1. On the computer, tablet or phone to type into, open Bluetooth settings.
  2. Add Voice Keyboard. No PIN needed.
  3. Put the cursor in a text field there, then tap Type a test.

It reconnects to that device by itself. To move it to another device, remove it there first, or use Forget paired devices in the tools (top right).
